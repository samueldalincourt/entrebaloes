# Google Translate attribution

`google-translate.png` is the unmodified color-regular@3x badge from the [official attribution archive](https://docs.cloud.google.com/static/translate/images/google-translate-attribution.zip), downloaded on 2026-10-27. It is shown with its original aspect ratio beside on-screen fast-mode results.

Usage follows the [ML Kit translation terms](https://developers.google.com/ml-kit/language/translation/translation-terms) and [Google Translate attribution requirements](https://docs.cloud.google.com/translate/attribution). This mark is not part of the app's name or logo and does not imply endorsement.

## Offline model

Version 1.6.0 downloads the official [Tencent Hy-MT2 1.8B GGUF](https://huggingface.co/tencent/Hy-MT2-1.8B-GGUF), revision and SHA-256 pinned in the Android model manifest. The weights are separate from this repository/APK. Its original Apache 2.0 license is included as `LICENSE-Hy-MT2.txt`. This app is an independent project and is not affiliated with or endorsed by Tencent.

`LICENSE-HY-MT.txt` records the different license of HY-MT1.5, evaluated during development but not selected as the shipped model.
